Overview

Clear task
management

Marte is a portal for analysing and managing tasks. The existing system was complex and difficult for workers to navigate — creating friction in daily operations and reducing productivity.

The challenge was transforming a cluttered, confusing interface into a clear, modern environment that workers could use and understand immediately without extensive training.

I designed a clean, structured web portal that simplified task workflows and made information hierarchy immediately apparent. The interface prioritises clarity over density — every element earns its place on screen.

Using OutSystems patterns as the component foundation ensured consistency with existing internal tools while introducing a significantly improved user experience.

Process

How It Was Built

01
Research
Interviewed workers and mapped existing task workflows. Identified the key pain points — information overload, unclear hierarchy, and too many steps to complete common actions.
02
Information Architecture
Restructured the task hierarchy and navigation. Designed a clear mental model — tasks, projects, and analytics — with logical groupings and progressive disclosure.
03
UI Design
Created a clean, modern dashboard and task views using OutSystems patterns. Focused on whitespace, clear typography, and visual hierarchy to reduce cognitive load.
04
Component Design
Designed reusable UI components — task cards, status filters, priority badges, and data tables — all built on OutSystems patterns for development efficiency.
05
Prototyping
Built interactive prototypes for the key task management flows — creating, assigning, tracking, and completing tasks — and validated with stakeholder walkthroughs.
06
Delivery
Delivered Sketch files with complete component specs aligned to OutSystems patterns. Included guidelines for data density, empty states, and responsive behaviour.
