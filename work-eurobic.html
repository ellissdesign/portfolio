Overview

Modern banking
for all ages

Eurobic needed a modern, clean homebanking experience that could be used easily by clients of all ages — from digital-native millennials to older customers less comfortable with technology.

The challenge was redesigning both the web and mobile applications with a fresh, contemporary aesthetic while keeping the interface intuitive and accessible to every demographic.

The redesign introduced a cleaner visual language, simplified navigation, and more useful functions for both clients and bank workers. Using OutSystems patterns as the foundation ensured consistency and development efficiency.

The result was a homebanking experience with a different ambient — modern, approachable, and designed to serve users regardless of their age or technical literacy.

Process

How It Was Built

01
Research
Studied existing user flows, demographics, and pain points. Identified key areas where the current interface created friction for older users and inefficiencies for bank workers.
02
Information Architecture
Mapped user journeys and simplified the navigation structure. Reduced cognitive load by grouping related functions and establishing clear visual hierarchies.
03
Wireframes
Created low-fidelity layouts for key flows — dashboard, transfers, account management — testing different approaches to information density and task completion.
04
UI Design
Designed high-fidelity interfaces using OutSystems patterns as the component foundation. Applied a clean, modern aesthetic with generous whitespace and clear typography.
05
Prototyping
Built interactive prototypes covering the main user journeys. Validated design decisions through internal reviews and usability walkthroughs with stakeholders.
06
Handoff
Delivered complete Sketch files with detailed specs aligned to OutSystems component patterns. Provided guidelines for responsive behaviour and edge cases.
