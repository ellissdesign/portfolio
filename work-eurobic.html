Overview

Modern banking
for all ages

The brief was simple to state and hard to do: create a modern, clean design with more useful functions for Eurobic clients and workers. The homebanking and mobile app had to bring a different ambient — contemporary and approachable — while staying easy to use for people of all ages.

That meant redesigning both the web and mobile applications with a fresh aesthetic without sacrificing the legibility and predictability that less technical users depend on.

The redesign introduced a cleaner visual language, simplified navigation, and more useful functions for both clients and bank workers. Using OutSystems patterns as the foundation ensured consistency and development efficiency.

The result was a homebanking experience with a different ambient — modern, approachable, and designed to serve users regardless of their age or technical literacy.

Problem & Goals

One product,
every kind of user

Eurobic's existing homebanking felt dated and uneven. Younger, digital-native customers expected the speed and clarity of modern apps, while older customers — less comfortable with technology — were easily lost in dense screens and unclear navigation. The same interface had to work for both, and for the bank workers using it daily.

A redesign couldn't simply chase a trend. It had to modernise the look and feel without trading away the legibility and predictability that less technical users depend on.

The goals were focused:

Modernise the visual language across web and mobile.
Simplify navigation and reduce cognitive load on key tasks.
Include every age group through accessible, predictable patterns.
Add value for bank workers with more useful, efficient functions.

Built on OutSystems patterns to keep delivery consistent and efficient.

Research & Discovery

Understanding
who banks here

Flows & pain points

I studied the existing user flows and mapped where people stalled — the friction points that slowed older users down and the inefficiencies that cost bank workers time. Seeing the current journeys end to end made the priorities obvious.

Demographics

The user base spanned a wide range of ages and confidence levels. That spread — not an average user, but a full spectrum — became the design constraint that everything else had to answer to.

Discovery reframed the brief from “make it look modern” to “make it modern and usable by everyone.” That distinction drove the simplified navigation, clearer hierarchy, and generous spacing that followed.

Design Decisions

Decisions &
rationale

Each decision balanced a modern aesthetic against the needs of the least confident user. A few choices shaped the rest.

Clarity over density. Generous whitespace and clear typography keep each screen scannable. For older users this reduces overwhelm; for everyone it makes the primary action obvious.

Simplified navigation. Related functions were grouped and the structure flattened, so common tasks take fewer steps and fewer decisions.

OutSystems as the foundation. Building on established component patterns kept the experience consistent and made development efficient — design and delivery speaking the same language.

Accessible by default. Predictable layouts, strong contrast, and consistent patterns meant accessibility was built into the system rather than bolted on at the end.

Brand & Style Guide

A documented
visual language

The redesign was backed by a style guide so the look and feel stayed consistent across web, mobile, and every team touching the product.

Typeface — Montserrat. A modern, characterful typeface used in Semibold for emphasis and Regular for body, chosen to give the app more personality while staying highly legible.

Process

How It Was Built

01
Research
Studied existing user flows, demographics, and pain points. Identified key areas where the current interface created friction for older users and inefficiencies for bank workers.
02
Information Architecture
Mapped user journeys and simplified the navigation structure. Reduced cognitive load by grouping related functions and establishing clear visual hierarchies.
03
Wireframes
Created low-fidelity layouts for key flows — dashboard, transfers, account management — testing different approaches to information density and task completion.
04
UI Design
Designed high-fidelity interfaces using OutSystems patterns as the component foundation. Applied a clean, modern aesthetic with generous whitespace and clear typography.
05
Prototyping
Built interactive prototypes covering the main user journeys. Validated design decisions through internal reviews and usability walkthroughs with stakeholders.
06
Handoff
Delivered complete Sketch files with detailed specs aligned to OutSystems component patterns. Provided guidelines for responsive behaviour and edge cases.
